# AI-BAZZAR

Сайт с backend на Node.js и постоянной базой SQLite. Требуется Node.js 24 или новее. Внешних npm-зависимостей нет.

## Запуск

```powershell
npm start
```

Откройте http://127.0.0.1:3000. Вёрстка и CSS сохранены; данные товаров загружаются из backend при открытии и обновляются в браузере раз в минуту. При открытии index.html напрямую доступен только встроенный демонстрационный каталог.

При первом запуске создаётся `data/bazzar.sqlite`. Исходные демонстрационные товары, предложения, история цен и рынки из `server/seed.json` загружаются один раз. Последующие запуски сохраняют изменения и заказы. Не удаляйте файл базы; для резервного копирования остановите сервер и скопируйте каталог `data`.

Настройки через переменные окружения: `PORT` (3000), `HOST` (127.0.0.1), `DATABASE_PATH` (по умолчанию `data/bazzar.sqlite` относительно проекта).

## API

- `GET /api/health` — проверка базы.
- `GET /api/catalog` — товары, предложения, история цен, рынки и лента.
- `GET /api/products?q=un&category=oziq-ovqat` — поиск и фильтрация.
- `GET /api/sync/status` — настройки расписания без секретов, время последней проверки, ошибки и ожидающие проверки записи.
- `POST /api/search` — локальный поиск и поиск отсутствующего товара в интернете с сохранением результатов.
- `GET /api/search/status` — состояние интернет-поиска, дневной бюджет и последнее обновление.
- `POST /api/orders` — сохранение заказа. JSON: `productId`, `offerId`, `quantity` (целое от 1 до 100000), `includeVat` (boolean), `customerName`, `phone`.

Сервер берёт цену выбранного предложения из базы и рассчитывает итог самостоятельно. Расчёт сохраняет исходную логику демосайта: опциональная надбавка 12% и доставка 12000 UZS за единицу. Это демонстрационные параметры, а не подтверждённые условия поставщиков. Ответ содержит номер заказа и рассчитанные суммы. Персональные данные заказов не выдаются через публичное API. Редактирование каталога и административный интерфейс пока не реализованы.

## Проверка

```powershell
npm test
```

Тест проверяет поиск, валидацию, защиту расчёта от подмены клиентской цены, сохранение после повторного открытия базы, ограничение размера запроса и закрытый доступ к серверным файлам.

## Текущий этап

Каталог расширен до 42 тестовых товаров. Добавлены поиск отсутствующих товаров в интернете через OpenAI Web Search, сохранение новых карточек/поставщиков и почасовой обход каталога. Подробнее: [настройка интернет-поиска](docs/online-search.md). Работают также синхронизация из HTTPS JSON API поставщиков и ИИ-проверка их данных. Предложения с подтверждённым перечислением на расчётный счёт имеют приоритет даже при более высокой цене.

Для интернет-поиска нужны ключ, модель и `ONLINE_SEARCH_ENABLED=true` в `.env`; отдельный фид не обязателен. Для фидов инструкция — [docs/product-sync.md](docs/product-sync.md). Без настроек онлайн-данные не загружаются. По умолчанию фоновый цикл обходит 10 запросов в час с общим бюджетом 100 исследований в сутки; это настраивается.

Заказы, отправленные через API, сохраняются локально и не отправляются поставщикам. Кнопка заказа на сайте сохраняет прежнее демонстрационное поведение и API не вызывает. Изображения, Tailwind, Font Awesome и Chart.js загружаются из интернета. Для публичного запуска потребуются HTTPS, защита от спама и авторизация администрации.
